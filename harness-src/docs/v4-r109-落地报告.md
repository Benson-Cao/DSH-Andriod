### ③ 动效层 —— 5 档 5 缓动 → 4 档 2 缓动

设计稿 07 只有一句话：**四档时长，不用中间值**。旧代码是 `100/160/220/320/480ms` + 5 条缓动，全部不走设计稿。

收口方式：旧名 `--dsh-mo-*` 保留为**别名**（mobile.js 与存量规则仍引用），取值一律转发到 v4 四档：

```css
--dsh-mo-instant:var(--dur-1);   /* 120ms */
--dsh-mo-quick:var(--dur-2);     /* 200ms */
--dsh-mo-base:var(--dur-2);      /* 200ms */
--dsh-mo-slow:var(--dur-3);      /* 320ms */
--dsh-mo-emphatic:var(--dur-4);  /* 450ms */
--dsh-mo-ease-std/out/emph/spring:var(--ease-out);
--dsh-mo-ease-in:var(--ease-io);
```

其余一并对齐：水波 `520ms → 450ms`（旧值不在四档内）、按压 `scale .955/.975 → .97`（设计稿统一 .97）、
焦点环 `--ds-brand-500 #5aa9f5 → var(--dsh-brand) #4D6BFE`。

**踩到一个坑**：设计稿自己第 447 行那条批量「换肤过渡」会把 `.btn` 的 `transform 120ms` 顶掉
（同特异性、后写者胜），于是 §motion 表格里写的「按压 120ms」在它自己的 CSS 里其实是不生效的。
本轮取表格意图，让**按压 120ms 与换肤 450ms 同时保留**：

```
.dsh-v4-btn transition = 0.12s ease-out (transform) + 0.45s ease-io ×3 (bg/color/border)
```

另：`.sheet` / `.tn` / `.g` **不在**设计稿那份批量名单里，所以它们保持各自的短过渡 ——
尤其 `.sheet` 必须是 320ms，一旦被 450ms 盖掉，收起就慢半拍。

### ④ Toast → 设计稿的居中胶囊

设计稿 `.toast` 是 `left:50%;top:50%` 的纯文字胶囊（`pad 12px 22px`、`bg --toast-bg`、`1px --line`、
`r-md`、`13.5px`、`shadow 0 12px 32px`、`blur(8px)`，进出 = `opacity 0→1 + scale(.94)→1`，`200ms ease-out`）。
旧实现是底部条 + 图标胶囊 + 两条堆叠 —— 三条都不在设计稿里，全部改掉。
JS 也从「每条新建 + 最多堆 2 条」改成**单例复用**（`DshMotion.toast()` 签名不变，`kind` 参数保留但不再产生视觉分支）。

### ⑤ 新增 5 个能力屏（手机端原本缺失）

挂在 harness 自建的 `#dsh-v4-layer`（`document.body` 直系，**不进 React 树**）。
为什么不往 dsh 里塞：dsh 是 React SPA，类名带构建哈希（`pI_x6G_` / `hHd-Xa_` / `bhn1Oq_`…），
往里塞 5 个整屏 = 把 5 处功能押在 5 个哈希上，任何一次发版都可能静默失效。

| 屏 | 名称 | 形态 | 数据来源 |
|---|---|---|---|
| S6 | 轨迹 Trajectory | 整屏页 | 现场抓当前会话步骤；抓不到回落设计稿示例，并在底部明示「示例数据」 |
| S7 | 工作区 · 文件与产物 | 整屏页 + 三段 Tab | 文件树从侧栏现场抓；Git 变更 / 产物预览用设计稿示例 |
| S8 | 任务看板 | 整屏页 + 横向五列 | 手机端无对应数据源 → 设计稿示例（设计稿 §08 已声明这些是示例） |
| S9 | 操作审批 Sheet | 底部 Sheet | 同上 |
| S10 | 指令面板 + Token 仪表盘 | 底部 Sheet | 同上 |

入口三个：

1. **抽屉「能力」分组 5 行**（轨迹 / 工作区 / 任务看板 / 指令面板 / 操作审批）—— 对应设计稿 S3
   「把网页端的 Git 图谱 + 手机入口提为一级动作」。沿用 r93/r74 的 `insertAdjacentElement` +
   每 600ms 复查套路，因为 React 重渲染会把注入行冲掉。
2. **输入框打 `/` 唤起指令面板**（设计稿 S10 原文）。⚠️ 加了三重闸门：只认 textarea /
   contenteditable，且只在内容**恰好等于 `/`** 的那一刻触发 —— 否则设置页填 NAS 路径
   （`/storage/...`）会凭空弹出面板。
3. `window.DshV4.open('traj'|'ws'|'kanban'|'approve'|'cmds')` API + Escape 关闭。

## 3. 已知限制（没做 / 做不到，先说清楚）

1. **S8 / S9 / S10 的数据是设计稿示例值**，手机端目前没有对应数据源。
   S6 / S7 尽量从现场 DOM 抓，抓不到才回落示例，且会在屏底部显式标注。
2. **S9 审批 Sheet 不是真审批**。要接真的，得拦 dsh 自己的权限弹窗
   （`_dialog_w1urq_22` 那套），风险较高，本轮没做；现在是显式入口 + `window.DshV4.open('approve')`。
3. **抽屉里塞了 5 行能力入口**，这是设计稿没有的额外行 —— 依据是 S3 的 stage-cap
   「把网页端的 Git 图谱 + 手机入口提为一级动作」。若要去掉，删 `mobile.js` 的 `CAPS` 数组即可。
4. **Toast 从底部条改成居中胶囊**，这是严格照设计稿改的。真机上它是 iOS/HMS 观感，
   如果你要 Android 惯用的底部条，改 `.dsh-mo-toast` 的定位即可（样式已与设计稿解耦成一份）。

## 4. 复现命令

```bash

./gradlew :app:assembleDebug --offline      # 约 22s

node scripts/cdp-eval.js "JSON.stringify(Object.keys(window.DshV4||{}))"
```
